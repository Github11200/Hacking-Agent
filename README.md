# Penetration Testing Agent

This agent is designed to perform penetration tests based on prompts given to it. The agent can:
- Scrape tool information from the list of tools on [Kali Linux's](https://www.kali.org/tools/) website
- Create a list of tools to install
- Install them on the system
- Use the tools to perform the penetration test

## Tech Stack
- Typescript + Bun JS
- [Mastra](https://mastra.ai/)
